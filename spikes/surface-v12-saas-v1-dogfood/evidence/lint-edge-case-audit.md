# Blind lint edge-case audit

Date: 2026-07-30

An independent reviewer inspected the data-only and Need-trace rules without
seeing the implementation plan. The review found the following ways a bundle
could look complete while still rendering unjustified, ambiguous, or broken
output.

| Edge case | Required result | Implemented check |
| --- | --- | --- |
| A custom widget renders nested configuration that the graph checker does not know about. | Refuse strict validation unless the resolved Registry contribution declares the renderer-owned `renderedConfigNodes` inventory and exact `deliveryContractId`. | `APP-GRAPH-RENDERED-NODE-SCOPE-UNKNOWN`, `APP-GRAPH-RENDERED-NODE-INVENTORY-INVALID`, and runtime `WIDGET-DELIVERY-CONTRACT-MISMATCH`. |
| A route title becomes an implicit navigation label. | Do not let the route Need silently justify a separately rendered navigation item. | `APP-GRAPH-RENDERED-NAVIGATION-IMPLICIT`; explicit navigation labels require direct current Need anchors. |
| A transition button derives its label from the destination route. | The DOM must expose both the transition and destination-route Need identities. | Surface transition rendering merges both direct anchors. |
| A Definition title or option, Component tab/table/summary child, or Locale string renders without its own reason. | Treat each nested visible value as a rendered node and require its direct current adopted Need. | Strict trace coverage now includes Definition roots and options, Component tab labels/summary items/table columns, and Locale strings. Renderers emit the matching Need identities. |
| A mounted Experience unit title is visible but has no direct reason, or an unmounted unit is counted as coverage. | Inventory titles only through mounted units and require each unit's own typed `needRefs` to resolve through its actor and tasks. | The rendered trace inventory includes `experience-unit-title`; the SaaS review records all 14 mounted titles and the control records its mounted title. |
| A hidden route or a route in another navigation scope changes shell membership without being audited. | Inventory every authored navigation entry, including hidden entries, and preserve `visible` and `scope` when selecting the active navigation. | Strict trace inventory includes all 14 SaaS navigation declarations; runtime navigation filters the nine visible `workspace` entries by the active scope without treating hidden declarations as absent evidence. |
| A Definition Bind or Shape changes rendered behavior without its own reason, or a Bind points to a missing item. | Validate each schema and Bind target, then require a direct current Need trace for every authored Bind and Shape. | Strict trace inventory includes `definition-bind` and `definition-shape`; the schema-backed verifier checks the SaaS bundle's seven Binds and their exact pointers. |
| A Theme changes the rendered product without a reason, applies document metadata as CSS variables, or silently changes the application root. | Require a direct current Need trace for the Theme document, keep tokens scoped to the rendered route subtree, and report contaminated roots instead of applying them. | Strict trace inventory includes `theme-document`; Surface React emits `THEME-DOCUMENT-ROOT-CONTAMINATED` and leaves invalid root values unapplied. |
| A Response Action label is an expression or object that the renderer cannot present as authored text. | Require a literal string label for every rendered Response Action and identify the exact action pointer on failure. | The trace inventory includes all 22 SaaS `response-action` labels; authoring reports the literal-label failure instead of inventing copy. |
| A preview source id exists in more than one catalog, or a scenario names a missing source, action, route, or profile. | Resolve only exact `(catalogRef, sourceRef)` pairs and fail closed on missing or ambiguous identities. | Surface preview-scenario schema and runtime validation. |
| A Data Source, widget data/action binding, scenario root, route-parameter set, source outcome, or action outcome changes behavior while inheriting a nearby reason. | Inventory each behavior unit separately and require its own current adopted Need anchor. Rows and cells inside one source outcome remain one unit. | Strict trace inventory now includes `data-source`, `surface-widget-data-binding`, `surface-widget-action-binding`, and all four preview-scenario behavior kinds. |
| The canonical scenario schema accepts trace fields but the runtime's closed structural check rejects them. | Exercise the same traced scenario through schema, runtime, artifact, and browser gates. | Focused Surface runtime regression plus the v12 browser startup check; `x-generation` and `routeParamsGeneration` remain data all the way to rendering. |
| A source is unavailable or its loaded payload fails the declared schema. | Preserve the unavailable outcome and render the normal diagnostic state; do not substitute invented success data. | Exact catalog/source resolution and payload validation convert absent, unavailable, or malformed source results into the explicit unavailable-source path. |
| Registry JSON Schemas are not executable, or input/output names collide. | Fail during graph validation rather than discovering the error in a renderer. | Executable-schema validation and duplicate Registry port-name diagnostics. |
| An Experience unit cites a missing actor, task, Definition item, or is never mounted. | Do not count the citation as product reasoning coverage. | `EXP-ACTOR-REF-UNRESOLVED`, `EXP-TASK-REF-UNRESOLVED`, `EXP-ITEM-REF-UNRESOLVED`, and `EXP-UNIT-UNMOUNTED`. |
| A rendered node resolves to a Need but no mounted Experience unit cites that Need, or an action/item relation is replaced by a broad Need match. | Keep exact unit, action, and item relations, require a mounted actor/task-resolved path, and block completion on every missing path. | Reasoning review reports `rendered_without_experience_path`; Wireframes tests cover broad matches and exact unit, item, and action authority. |
| A Registry declaration and the delivered renderer implementation drift. | Refuse to render the widget. | Runtime equality check over delivery-contract id, Registry entry version, and rendered-node inventory. |
| Validation or browser evidence predates a mutation, a screenshot changed, or a required phase was omitted. | Export remains incomplete. | Closed reviewed-input digest, recorded screenshot hashes, mechanically recomputed reasoning review, and seven required AppGraph phase results. |
| StructuredPanel ids or outputs collide, an action is not bound, a label cannot be rendered, or a data path is impossible under its exact source schema. | Produce named authoring errors at the exact config pointer. | `STRUCTURED-PANEL-*-DUPLICATE`, `STRUCTURED-PANEL-ACTION-UNBOUND`, `STRUCTURED-PANEL-ACTION-LABEL-NON-LITERAL`, and `STRUCTURED-PANEL-DATA-PATH-IMPOSSIBLE`. |
| Product-specific executable code survives beside a structured bundle. | The test fails even when the browser looks correct. | The generic-host source guard scans for product terms, route ids, field ids, action tables, and shell render overrides. |

Open schemas remain conservative: lint reports only paths proven impossible.
The scenario runtime validates the selected payload before rendering and reports
runtime absence or shape failure through the normal diagnostic channel.
